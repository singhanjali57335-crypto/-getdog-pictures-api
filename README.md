# getdog-pictures-api

A simple web project that fetches and displays a **random dog image** every time the user clicks the button.

##  Features

* Get a random dog image with one click
* Uses the Dog API
* Uses **Axios** to make an API request
* Simple and beginner-friendly JavaScript project

##  Technologies Used

* HTML
* JavaScript
* Axios
* Dog CEO API

##  How It Works

1. Click the **Get Random Dog** button.
2. JavaScript sends a request to the Dog API using Axios.
3. The API returns a random dog image URL.
4. The image is displayed on the webpage.

##  API Used

Dog CEO API: `https://dog.ceo/api/breeds/image/random`
